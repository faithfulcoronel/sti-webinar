# Design

This folder holds the design that the app was built from. It stands in for a Figma file.

- `design-spec.md`: colors, fonts, frames, component states, and the logic the design does not say.
- `mockup/`: source of the design canvas. Seven frames: desktop register, validation errors, confirmation, mobile 390, organizer sign-in, organizer list, and styles and components. The `.dc.html` files are the frames; `canvas.json` is their layout on the canvas.

Live canvas (private to the owner unless shared): https://claude.ai/artifact/B6d2Cvp87xexbn74G18n42

All names and emails in the mockup are invented test data.
